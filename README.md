
# Social Media Data Analysis (SQL)

## 📌 Project Overview
An end-to-end data analysis project using **SQL** to evaluate social media user engagement, content performance, and key platform metrics. This project includes relational database queries, a detailed technical report, and an executive presentation deck.

---

## 📁 Deliverables Included
* **`social_media_queries.sql`** — Complete SQL script with data extraction, aggregations, CTEs, and window functions.
* **`social_media_report.docx`** — In-depth analysis report detailing business impact, insights, and strategy recommendations.
* **`social_media_presentation.pptx`** — Executive slide deck summarizing key findings for stakeholders.
* **`query_dashboard_preview.png`** — Visual preview of SQL query results and summary charts.

---

## 🛠️ Tech Stack & SQL Concepts Used
* **SQL (Database Management & Querying)**:
  * Aggregations (`GROUP BY`, `HAVING`, `COUNT`, `SUM`, `AVG`)
  * Multi-table Joins (`INNER JOIN`, `LEFT JOIN`)
  * Advanced SQL (`Subqueries`, `CTEs`, `Window Functions` like `ROW_NUMBER()` / `RANK()`)
* **Microsoft Word & PowerPoint**: Reporting and executive presentation design.
